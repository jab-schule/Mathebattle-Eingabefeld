Mathebattle-Tastenfeld

Ein Lesezeichen, das auf einer Mathebattle-Aufgabe ein Tastenfeld mit Brüchen, Hochzahlen und e-Funktionen einblendet. Der Term wird beim Tippen ins Mathebattle-Feld übertragen, die Vorschau und das Abschicken laufen wie gewohnt über Mathebattle.

Bei Aufgaben, in denen abgeleitet werden soll, gibt es drei Versuche: Eine falsche Antwort wird vorher abgefangen, erst der dritte Versuch geht ungeprüft an Mathebattle. Ist die Ableitung richtig, aber noch nicht vereinfacht, gibt es einen Hinweis, ohne dass ein Versuch verloren geht.

Auf dem iPad oder iPhone einrichten

  1. Kopiere den Code mit dem Button unten.
  2. Öffne in Safari irgendeine Seite, tippe auf das Teilen-Symbol und wähle „Lesezeichen hinzufügen“. Nenne es „MB Tastenfeld“ und sichere es.
  3. Öffne die Lesezeichen über das Buch-Symbol, tippe auf „Bearbeiten“ und dann auf „MB Tastenfeld“. Lösche die Adresse, füge den kopierten Code ein und tippe auf „Fertig“.
  4. Öffne bei Mathebattle eine Aufgabe. Öffne dann die Lesezeichen über das Buch-Symbol oder über die drei Punkte neben der Adresse und tippe dort auf „MB Tastenfeld“. Das Tastenfeld erscheint unten auf der Seite.

Starte das Lesezeichen immer aus der Lesezeichenliste. Über die Vorschläge in der Adressleiste blockiert Safari es mit der Meldung „Skript kann nicht ausgeführt werden“.

Am Computer einrichten

Zieh diesen Link in die Lesezeichenleiste deines Browsers. Auf Mathebattle klickst du dann auf das Lesezeichen.

Code

Das Lesezeichen lädt das Tastenfeld jedes Mal frisch von dieser Seite. Verbesserungen kommen dadurch automatisch bei allen an. Einmal antippen reicht für die ganze Sitzung: Das Tastenfeld bleibt beim Abschicken und bei der nächsten Aufgabe erhalten. Erst wenn du die Seite selbst neu lädst, musst du das Lesezeichen wieder antippen. Ein erneutes Antippen blendet das Tastenfeld aus oder wieder ein.
